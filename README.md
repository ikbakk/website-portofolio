# Full-stack engineer portfolio

Astro source lives in `src/pages/index.astro`. Portfolio content is in `src/data/portfolio.ts`; the world map and Lenis scroll behavior live in `src/components/`. The navigation and sections comparison pages remain at `/navigation-lab/` and `/sections-lab/`.

Run locally:

```sh
npm install
npm run dev
```

Build for production with `npm run build`. `index.html` is a viewable snapshot of the build for the project file preview. The previous directory clone is preserved as `index-v2.html`.

The selected work, experience, and contact details were recovered from the earlier portfolio source in Git. Confirm current project states, external links, and contact details before publishing.
