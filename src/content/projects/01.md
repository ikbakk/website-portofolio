## The problem

Sungkar Group is a Lombok-based tour operator. Travelers need to understand routes,
package options and inclusions before they can ask a useful question about a trip.
The same content also needs to work across languages and search entry points.

## My contribution

I built the marketing and content surface with Astro and TypeScript. Package
information lives in structured content rather than being duplicated across
individual page components. That structure supports destination pages, package
detail pages and localized versions of the same information.

## Decisions that shaped it

Static rendering keeps the main content available before JavaScript runs.
Canonical URLs, XML sitemaps, Open Graph metadata and package structured data
support discoverability and sharing. Responsive imagery and WebP delivery keep
the visual material separate from the content model.

The repository now includes Indonesian, English, Arabic, Malay and Chinese
locales. Layout and content need to accommodate those different reading patterns,
including right-to-left Arabic.
